Setup de notebooks

Gerador de script de configuração

Marque só as etapas que você vai executar nesta máquina, preencha os campos pedidos e o script .ps1 é montado ao vivo ao lado.

Etapas

01
Usuário "indi"
Nova senha + adicionar ao grupo Administradores
02
Conta Administrador
Nova senha + nunca expira + habilitar conta
03
Nome do computador
Renomeia o host (aplica após reiniciar)
Máx. 15 caracteres, sem espaços ou acentos.
04
Páginas de instalação
Abre downloads: LibreOffice, Adobe Reader, 7-Zip, Teams, Chrome, Firefox, Edge*, AnyDesk, FortiClient
*Edge só abre se ainda não estiver instalado na máquina.
